- [ ] **Implementar meta tags** básicas (title, description)

- [ ] **Setup Twitter Cards** meta tags
- [ ] **Implementar canonical** tags
- [ ] **Configurar hreflang** para i18n

- [ ] **Otimizar imagens** (WebP, lazy loading)

## 🎯 CHECKLIST DE QUALIDADE

### ✅ Antes de Publicar Qualquer Conteúdo

#### SEO On-Page
- [ ] **Title tag** otimizado (≤60 caracteres)
- [ ] **Meta description** persuasiva (150-155 caracteres)
- [ ] **H1 único** e com keyword principal
- [ ] **Estrutura H2-H6** lógica
- [ ] **Keywords naturalmente** distribuídas
- [ ] **Internal links** relevantes (3-5 por página)
- [ ] **External links** para fontes autoritárias
- [ ] **Alt text** em todas as imagens
- [ ] **URL amigável** e descritiva
- [ ] **Canonical tag** configurado

#### Qualidade de Conteúdo
- [ ] **Mínimo 1.200 palavras** (artigos)
- [ ] **Responde search** intent completamente
- [ ] **Inclui FAQ** section relevante
- [ ] **CTA claro** e persuasivo
- [ ] **Prova social** quando aplicável
- [ ] **Disclaimer compliance** quando necessário
- [ ] **Formatação escaneável** (bullets, listas)
- [ ] **Imagens otimizadas** e relevantes
- [ ] **Tempo de leitura** apropriado
- [ ] **Call-to-action** estratégico

#### Técnico
- [ ] **Page speed** <3s mobile
- [ ] **Mobile-friendly** design
- [ ] **Schema markup** implementado
- [ ] **Social sharing** tags
- [ ] **Breadcrumbs** funcionais
- [ ] **404 errors** verificados
- [ ] **Redirect chains** evitados
- [ ] **Duplicate content** verificado
- [ ] **Crawlability** confirmada
- [ ] **Indexability** testada
